C Programming Practice

This repository contains my C programming practice programs as I learn the fundamentals of programming.

Programs

Day of the Week: Uses a switch statement to display the day corresponding to a number from 1 to 7.

Input Validation: Checks whether the user enters a valid integer.

Concepts Covered

Basic input and output (printf and scanf)

Variables and data types

Switch statements

Conditional statements

Input validation

How to Run

Compile the program using GCC:

gcc 01-basics/day_of_week.c -o day_of_week

Run it:

Windows: day_of_week.exe

Linux/macOS: ./day_of_week
